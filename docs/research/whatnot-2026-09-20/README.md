# Whatnot field study, September 20, 2026

`data.json` contains the observations and explicit modeling assumptions. `build.py` is the editable report source and generates all charts from those values, then writes the eight-page PDF to `public/research/whatnot-market-study-2026-09-20.pdf`.

Rebuild from the repository root:

```sh
python3 docs/research/whatnot-2026-09-20/build.py
```

Dependencies: Python 3, matplotlib, reportlab. Source photos are unmodified supplier/auction product images, reproduced with attribution for product comparison. They are not photographs of the observed Whatnot sale lots. Charts are generated locally; no AI product imagery is used. Do not add signed-in browser captures or private seller analytics to this public PDF.

Prices, inventory and audience counts are dated snapshots. Supplier inventory and auction outcomes must be rechecked before purchasing. Models exclude income taxes and fixed business overhead; labor is a planning allowance, not measured performance.
